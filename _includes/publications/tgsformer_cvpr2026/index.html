TGSFormer: Scalable Temporal Gaussian Splatting for Embodied Semantic Scene Completion

CVPR 2026

Rui Qian*, Haozhi Cao*, Tianchen Deng*, Tianxin Hu, Weixing Guo, Shenghai Yuan, Lihua Xie

We propose TGSFormer, a scalable Temporal Gaussian Splatting framework that maintains persistent Gaussian memory for temporal prediction with dual temporal encoding and confidence-aware voxel fusion. It achieves state-of-the-art results on embodied SSC benchmarks using significantly fewer primitives.
